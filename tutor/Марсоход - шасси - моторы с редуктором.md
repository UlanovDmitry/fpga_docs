# Марсоход — шасси: управление моторами с редуктором (Verilog)

Разбор реализации управления моторами **с редуктором** в «шасси»-проектах плат Марсоход по сводке [Марсоход - проекты.md](../links/Марсоход%20-%20%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82%D1%8B.md).

Современные шасси-проекты (платы MA3128, Marsohod3GW2) используют **шаговый двигатель 28BYJ-48** — в его корпус встроен **понижающий планетарный редуктор ~1:64** — и готовый драйвер на **ULN2003**. FPGA не формирует ни PWM, ни замкнутого контура: Verilog только вырабатывает **4-фазную шаговую последовательность**, тактируемую от свободного счётчика.

Исходники — GitHub-организация [marsohod4you](https://github.com/marsohod4you):

| Проект (статья) | Мотор | Код |
|---|---|---|
| Марсоход, управляемый ИК-пультом (`IR-ctrl-bot`) | 28BYJ-48 ×2 | [MA3128 → `IR-ctrl-bot`](https://github.com/marsohod4you/MA3128/tree/main/IR-ctrl-bot) |
| Beam-робот: машинка по полосе (`Beam-ctrl-bot`) | 28BYJ-48 ×2 | [MA3128 → `Beam-ctrl-bot`](https://github.com/marsohod4you/MA3128/tree/main/Beam-ctrl-bot) |
| Марсоход из браузера v2.0 (`_phone-ctrl-bot`) | 28BYJ-48 ×2 | [Marsohod3GW → `_phone-ctrl-bot`](https://github.com/marsohod4you/Marsohod3GW/tree/Marsohod3GW2_GW1NR-LV9QN88PC6I5/_phone-ctrl-bot) |
| Управление 4 шаговыми из Raspberry (`rpi-serial4steppers`) | 28BYJ-48 ×4 | [MA3128 → `rpi-serial4steppers`](https://github.com/marsohod4you/MA3128/tree/main/rpi-serial4steppers) |

Старые проекты (плата Марсоход, MAX II, 2010: машинка «Марсоход», «Гусеничный Марсоход», «Двигаться по полосе») — моторы от HDD **без редуктора** (BLDC, 3 обмотки), коммутировались напрямую выводами ПЛИС; их Verilog-код распространялся архивами Quartus II со страниц статей, отдельных репозиториев нет.

## 1. Железо: 28BYJ-48 + ULN2003

**28BYJ-48** — униполярный шаговый двигатель, 4 фазы, обычно 5 В. Внутри — быстрый ротор (32 шага на оборот) и **встроенный пластмассовый редуктор ≈64:1**, поэтому на выходном валу:

- **full-step** (4 состояния фаз): `32 × 64 ≈ 2048` шагов на оборот вала;
- **half-step** (8 состояний фаз): `64 × 64 ≈ 4096` полушагов на оборот вала.

Редуктор даёт нужный тележке момент и низкую скорость вала — «медленно, но сильно».

Драйвер — готовая платка на **ULN2003** (сборка Дарлингтона): входы `IN1..IN4` + питание 5 В / GND. На плате MA3128 под драйверы есть 4 разъёма с портами `MA[3:0]`, `MB[3:0]`, `MC[3:0]`, `MD[3:0]` (в IR-ctrl-bot и Beam-ctrl-bot задействованы MA и MB).

Привязка выводов из `max.qsf` (MA3128, EPM3128ATC100):

```
MA[0]=PIN_81  MA[1]=PIN_79  MA[2]=PIN_76  MA[3]=PIN_72
MB[0]=PIN_80  MB[1]=PIN_77  MB[2]=PIN_75  MB[3]=PIN_71
```

## 2. Модуль `motor.v` (full-step, MA3128)

Один и тот же файл в `IR-ctrl-bot` и `Beam-ctrl-bot`:

```verilog
module motor(
	input wire clk,
	input wire enable,
	input wire dir,
	input wire [2:0]cnt8,      // 3 бита от свободного счётчика
	output reg f0, f1, f2, f3  // 4 фазы -> ULN2003 IN1..IN4
);

always @(posedge clk)
	if( ~enable ) begin        // СТОП: все фазы выключены
		f3 <= 1'b0; f2 <= 1'b0; f1 <= 1'b0; f0 <= 1'b0;
	end
	else
	if(dir) begin              // ВПЕРЁД: прямое направление
		f0 <= (cnt8[1:0]==0 || cnt8[1:0]==3);
		f1 <= (cnt8[1:0]==0 || cnt8[1:0]==1);
		f2 <= (cnt8[1:0]==1 || cnt8[1:0]==2);
		f3 <= (cnt8[1:0]==2 || cnt8[1:0]==3);
	end
	else begin                 // НАЗАД: обратная последовательность
		f3 <= (cnt8[1:0]==0 || cnt8[1:0]==3);
		f2 <= (cnt8[1:0]==0 || cnt8[1:0]==1);
		f1 <= (cnt8[1:0]==1 || cnt8[1:0]==2);
		f0 <= (cnt8[1:0]==2 || cnt8[1:0]==3);
	end
endmodule
```

Идея: **никакого конечного автомата шагов нет** — состояния «генерирует» сам счётчик. Используются 2 младших бита `cnt8[1:0]`, т.е. четыре состояния, которые циклически прогоняют комбинации фаз (`1` = фаза под напряжением):

| `cnt8[1:0]` | f3 f2 f1 f0 | Фазы под напряжением |
|---|---|---|
| 0 | 0 0 1 1 | A B |
| 1 | 0 1 1 0 | B C |
| 2 | 1 1 0 0 | C D |
| 3 | 1 0 0 1 | D A |

Это классический **full-step «две фазы включены»**. При `dir=0` порядок обхода состояний обратный → ротор (и вал редуктора) вращается в другую сторону.

## 3. Модуль `motor.v` (half-step, Gowin `_phone-ctrl-bot`)

Версия для Marsohod3GW2 использует все 3 бита `cnt8` (0..7) — полушаг, плавнее и точнее по углу:

```verilog
always @(posedge clk)
	if( ~enable ) begin
		f3 <= 1'b0; f2 <= 1'b0; f1 <= 1'b0; f0 <= 1'b0;
	end
	else
	if(dir) begin              // ВПЕРЁД
		f0 <= (cnt8==0 || cnt8==6 || cnt8==7 );
		f1 <= (cnt8==0 || cnt8==1 || cnt8==2 );
		f2 <= (cnt8==2 || cnt8==3 || cnt8==4 );
		f3 <= (cnt8==4 || cnt8==5 || cnt8==6 );
	end
	else begin                 // НАЗАД
		f3 <= (cnt8==0 || cnt8==6 || cnt8==7 );
		f2 <= (cnt8==0 || cnt8==1 || cnt8==2 );
		f1 <= (cnt8==2 || cnt8==3 || cnt8==4 );
		f0 <= (cnt8==4 || cnt8==5 || cnt8==6 );
	end
```

Последовательность: `1100 → 0100 → 0110 → 0010 → 0011 → 0001 → 1001 → 1000` (полушаг, попеременно одна/две фазы).

## 4. Тактирование шагов

В топ-уровне (`max.v` для MA3128, `top.v` для Marsohod3GW2) — свободный счётчик на полной частоте и «бесплатный» делитель старшими битами:

```verilog
reg [20:0] cnt = 0;
always @(posedge CLK) cnt <= cnt+1;   // CLK = 80 МГц (MA3128)

motor motor_inst0(
	.clk   (CLK),
	.enable( motor0_ena | (~KEY[0]) ), // команда или кнопка на плате
	.dir   ( motor0_dir ),
	.cnt8  ( cnt[19:17] ),             // таймер шагов
	.f0( MA[0] ), .f1( MA[1] ), .f2( MA[2] ), .f3( MA[3] )
);
```

- Старшие биты счётчика работают как **делитель частоты**: состояние фаз меняется каждые `2^17` тактов.
- Частота шагов: `80 МГц / 2^17 ≈ 610 Гц` (шаг каждые ~1,64 мс).
- Скорость выходного вала редуктора: full-step `610/2048 ≈ 0,30 об/с ≈ 18 об/мин`; half-step `≈ 0,15 об/с ≈ 9 об/мин`.
- Скорость задаётся **жёстко выбором бита счётчика**; плавного разгона / регулировки скорости нет.

## 5. Дифференциальный привод: движение и повороты

Тележка — две независимые пары «модуль `motor` + драйвер»: левое колесо на `MA`, правое на `MB`. Движение и развороты задаются комбинацией направлений `dir` обоих моторов.

В `IR-ctrl-bot/max.v` декодер ИК на `clk39K = cnt[11]` (80 МГц/2048 ≈ 39 кГц) захватывает сигнал приёмника ILMS5360 с порта `MD[0]` в двухбитный сдвиговый регистр `ir_reg`, счётчик `ir_cnt` измеряет длительности импульсов, а 32-битный сдвиговый регистр `cmd` накапливает код команды пульта Samsung. По младшему байту команды:

```verilog
if( cmd[7:0]==8'hF9 ) begin // forward
	motor0_ena<=1; motor0_dir<=1; motor1_ena<=1; motor1_dir<=1; end
else if( cmd[7:0]==8'h79 ) begin // backward
	motor0_ena<=1; motor0_dir<=0; motor1_ena<=1; motor1_dir<=0; end
else if( cmd[7:0]==8'hB9 ) begin // left (колёса в разнобой)
	motor0_ena<=1; motor0_dir<=0; motor1_ena<=1; motor1_dir<=1; end
else if( cmd[7:0]==8'h59 ) begin // right
	motor0_ena<=1; motor0_dir<=1; motor1_ena<=1; motor1_dir<=0; end
else if( cmd[7:0]==8'hE9 ) begin // stop
	motor0_ena<=0; motor0_dir<=0; motor1_ena<=0; motor1_dir<=0; end
```

`enable = motor_ena | (~KEY[i])` — кнопки на плате работают как резервное ручное управление.

- **`Beam-ctrl-bot`** — то же, но `enable` формируют оптические датчики `opto0_r/opto1_r` (следование по линии), а `dir` зашит в `1'b1`.
- **`_phone-ctrl-bot`** (Gowin) — команды приходят как звуковые тоны с телефона: ADC1175 оцифровывает звук, модуль измеряет период и выбирает `STATE_FORWARD/BACKWARD/LEFT/RIGHT/STOP`, дальше — та же таблица `motor0_dir/motor1_dir`.

## 6. Управление 4 моторами по UART: `rpi-serial4steppers`

Здесь шаги продвигает **хост** (Raspberry через `serial.v`, 115200 бод): FPGA лишь преобразует `cnt8` в комбинацию фаз. Регистр `control[7:0]` задаёт step/dir/halfstep/sleep/reset и адрес мотора:

```verilog
parameter IDX = 0;
wire ctrl_step;     assign ctrl_step  = control[0]; // один шаг по команде
wire ctrl_dir;      assign ctrl_dir   = control[1];
wire ctrl_halfstep; assign ctrl_halfstep = control[2];
wire ctrl_sleep;    assign ctrl_sleep = control[3];
wire ctrl_reset;    assign ctrl_reset = control[4];
wire [1:0]ctrl_addr; assign ctrl_addr = control[6:5];

reg [2:0]cnt8 = 3'd0;
always @(posedge clk)
	if( wr && ctrl_addr==IDX ) begin
		sleep    <= ctrl_sleep;
		halfstep <= ctrl_halfstep;
		if( ctrl_reset )     cnt8 <= 3'd0;
		else if( ctrl_step ) cnt8 <= ctrl_dir ? cnt8+1'b1 : cnt8-1'b1;
	end
```

Четыре экземпляра `#(.IDX(0..3))` подключены к `MA/MB/MC/MD` — так можно дозировать количество шагов и, через редуктор, точный угол поворота выходного вала.

## 7. Итоговая схема

```
FPGA (MA3128 / Marsohod3GW2)
  max.v / top.v
    ├── cnt[20:0]  ──►  cnt[19:17] = таймер шагов (~610 Гц)
    ├── декодер команд (ИК / оптодатчики / UART / тоны)
    │        └── motor_ena, motor_dir
    └── motor.v ×2 (или ×4)
            └── f0..f3 ──► ULN2003 (IN1..IN4) ──► 28BYJ-48 (редуктор ~1:64)
```

**Итог.** Verilog отвечает только за три вещи: последовательность фаз `f0..f3` (из счётчика), `enable` (вкл/выкл) и `dir` (направление). Усиление момента и нужную низкую скорость вала обеспечивает **механический редуктор внутри 28BYJ-48**. Это минимальная схема управления шаговым мотором: без ШИМ, без обратной связи и без плавного пуска — только свободный счётчик и комбинационная логика фаз.
