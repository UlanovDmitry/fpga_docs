## EBAZ4205

| Цель | Репозиторий / материал |
|------|------------------------|
| Готовый Linux с образами | `nightseas/ebit_z7010` |
| Своя сборка Linux (Buildroot) | `blkf2016/ebaz4205` |
| PetaLinux, свежие версии | `wavelet2/EBAZ4205` или `har-in-air/EBAZ4205_PETALINUX` |
| PYNQ | `Stavros/ebaz4205` |
| Bare-metal / PL | `trebisky/ebaz4205_miner` |
| Учебные примеры | `tomorrow56/EBAZ4205_tutorial` |
| Yocto / `.wic` одной командой | `embed-me/meta-ebaz4205` |
| Buildroot без PetaLinux | `embed-me/ebaz4205_buildroot` |

**Linux на SD (максимально полный путь из имеющегося):**

1. Схема и пины — **xjtuecho** (KiCad, XDC-шаблон) + **Elrori** (рабочий DTS/uEnv)
2. Сборка — **blkf2016** (FSBL, Buildroot, Vivado TCL)
3. Плата расширения HDMI — отдельно **Elrori EBAZEXT-V2** + свой PL + драйверы

## Antminer S9 / T9+ / E3

| Цель | Репозиторий / материал |
|------|------------------------|
| Bare-metal | `KarolNi/S9miner_sample` + `trebisky/Antminer` |
| Linux / PetaLinux | `polprog/antminer_zynq` (заготовка) + [U-Boot DTS](Linux%20-%20ресурсы.md) |
| PYNQ | `kangyuzhe666/zynq7010-pynq-2.5` или `guannan-he/Antminer_s9_pynq` |
| PYNQ на T9 | `opensatellite/antminer_t9` |
| SDR / серьёзный PL | `iliasam/OpenZynqSDR_HW` |
| Плата расширения | `astranome/Astra_S9_FPGA_Base` или `cropinghigh/zynq_a9_mb` |

**Bare-metal:**

1. Примеры — **KarolNi** P01→P04
2. DTS для ориентира — **polprog**
3. Boot chain, U-Boot с SD — **trebisky** ([Antminer index](http://cholla.mmto.org/zynq/antminer/))

**Полный Linux — собирать самому** по аналогии с blkf2016 + DTS из polprog/Xilinx.
