# Термины для отладочных плат SoC

Разбор терминов из [Репозитории.md](Репозитории.md): таблицы репозиториев, привязка к плате, логика PS/PL, сводки и практическая карта.

---

## SoC и плата

| Термин | Что это | Зачем |
|--------|---------|-------|
| **Zynq-7000 / Zynq-7010 (XC7Z010)** | SoC Xilinx: двухъядерный Cortex-A9 (PS) + FPGA (PL) в одном кристалле | Базовая платформа всех перечисленных плат |
| **PS (Processing System)** | «Процессорная» часть Zynq: ARM, DDR-контроллер, MIO, периферия | Здесь крутится FSBL, U-Boot, Linux, bare-metal |
| **PL (Programmable Logic) / fabric** | Программируемая FPGA-часть Zynq | Свой RTL, обвязка EMIO, ускорители, интерфейсы к хеш-платам |
| **DDR3** | Оперативная память PS (у EBAZ4205 — 256 MB) | Рабочая память загрузчиков, ядра и приложений |
| **NAND flash** | Неволатильная память на плате (128 MB у EBAZ4205) | Штатная загрузка майнера, хранение bitstream и rootfs |
| **boot select** | Резистор/перемычка, выбирающая источник загрузки (NAND vs SD) | На EBAZ4205 для SD нужно припаять разъём и переставить резистор |
| **control board** | Плата управления майнером (Antminer S9, EBAZ4205) | Zynq + сеть + интерфейс к хеш-платам |
| **хеш-платы / DATA1–3** | Вычислительные платы майнера; разъёмы DATA1/2/3 на EBAZ4205 | Обмен данными через PS (штатный cgminer/bmminer) или PL (`top_ctrl`) |
| **J3 / J5** | Разъёмы на EBAZ4205 (упоминаются в XDC и boot log) | Возможные PWM/сигналы управления в штатном bitstream |
| **PHY** | Ethernet-трансивер на плате | Связь PS через GEM (MII/GMII/RGMII); адрес PHY задаётся в DTS |
| **Fast Ethernet / Ethernet 100M** | Сеть 100 Мбит/с на платах управления | На S9 — полноценный Ethernet; на EBAZ4205 — MII через EMIO |

## Привязка к плате

| Термин | Что это | Зачем |
|--------|---------|-------|
| **Привязка (pin mapping)** | Согласованное описание «сигнал → пин/адрес» в PS7, XDC и DTS | Без неё периферия не работает или работает не на тех ножках |
| **PS7 / Block Design (BD)** | Графическая настройка processing_system7: MIO, EMIO, такты, периферия | Источник истины для MIO; основа Vivado-проекта |
| **`processing_system7_0`** | IP-ядро PS7 в Vivado Block Design | Центральный блок любого Zynq-проекта |
| **MIO** | Multiplexed I/O — пины PS, не требующие PL/XDC | NAND, UART1, SDIO, GPIO кнопок — всё на MIO |
| **EMIO** | Расширение PS-периферии через PL на BGA-пины | LED, второй UART, Ethernet — нужен bitstream + XDC |
| **XDC** | Файл constraints Vivado: логический сигнал → физический пин | Вход в сборку bitstream; активный (Elrori, blkf2016) или шаблон (xjtuecho) |
| **Шаблон XDC (пины закомментированы)** | Справочник пинов без активных constraints | Документация; нужно раскомментировать под свой top-модуль |
| **Vivado TCL-скрипт** (`ebaz4205.tcl`) | Скрипт, создающий Block Design (PS7, EMIO Ethernet…) | Воспроизводимая генерация аппаратного описания (blkf2016) |
| **top-модуль** | Верхний RTL-модуль PL, порты которого привязываются в XDC | Имена портов в XDC должны совпадать с top-модулем |
| **DTS / DTB** | Device Tree Source / скомпилированный бинарник: описание железа для ядра/U-Boot | Кнопки, LED, Ethernet, UART, SD — узлы в `.dts` |
| **U-Boot DTS** vs **kernel DTS** | DTS для загрузчика и для ядра (могут отличаться) | polprog — только U-Boot DTS; полный Linux нуждается в обоих |
| **`&gem0`, `&uart0/1`, `&sdhci0`, `&nfc0`, `&smcc`** | Узлы Device Tree: Ethernet, UART, SD, NAND | Включение/настройка периферии в DTS |
| **`gpio-leds` / `gpio-keys`** | Узлы DTS для LED и кнопок | В polprog отсутствуют — LED/кнопки там не описаны |
| **`phy-mode`** | Режим Ethernet в DTS: `"mii"`, `"rgmii-id"` и т.д. | Должен совпадать с PHY и обвязкой PL; у blkf2016 возможное расхождение MII vs rgmii-id |
| **`reserved-memory` / `fpga_space`** | Зарезервированная область RAM для доступа к PL (0x0F000000, 16 MB) | Типично для AXI-регистров управления хеш-платами |
| **`.bd`** | Файл Block Design Vivado | KarolNi: `P0x_*/.../zynq.bd` — привязка через MIO |
| **`zynq_ooc.xdc`** | Служебные constraints для out-of-context синтеза | Не карта платы; служебный файл Vivado (KarolNi) |
| **`PCW_EN_EMIO_GPIO`** | Параметр PS7: включение EMIO для GPIO | В KarolNi = 0 — только MIO, без EMIO |
| **card detect SD** | Сигнал обнаружения SD-карты (MIO 34 в P01_HELLO) | Опциональная линия SDIO помимо MIO 40–45 |

## Периферия и интерфейсы

| Термин | Что это | Зачем |
|--------|---------|-------|
| **MII / GMII / RGMII / MDIO** | Варианты интерфейса Ethernet между MAC (PS) и PHY | EBAZ4205 — MII на плате; blkf2016 подгоняет 4-бит PHY к 8-бит GMII через PL |
| **UART / UART0 / UART1** | Последовательная консоль; UART1 — типичная консоль на MIO | Hello World, boot log, отладка |
| **SDIO0 / SD-карта** | Интерфейс SD-карты на MIO 40–45 | SD-boot, FatFs-тесты, Linux rootfs с карты |
| **NFC / SMCC** | NAND Flash Controller в PS7 | Загрузка и хранение штатной прошивки майнера |
| **GPIO / MIO GPIO** | Цифровые входы/выходы на MIO или EMIO | LED, кнопки; номер gpio = номер MIO в bare-metal |
| **HDMI OUT** | Видеовыход на плате расширения EBAZEXT-V2 | Требует PL-логики (TMDS), в репо нет RTL |
| **VGA** | Видеовыход в EBAZEXT-V1 (XDC) | PL-пины заданы, RTL отсутствует |
| **CMOS / CMOS-камера** | Параллельный интерфейс камеры на плате расширения | Аппаратная разводка есть; захват — свой FPGA-проект |
| **JTAG** | Отладочный интерфейс (упоминается в xjtuecho) | Прошивка и отладка через Vivado/hardware manager |
| **watchdog** | Сторожевой таймер PS (в U-Boot DTS polprog) | Перезагрузка при зависании |
| **AXI-регистры** | Регистровый интерфейс PL, доступный PS по шине | Штатный bitstream майнера — управление хеш-платами |

## FPGA / Vivado / PL

| Термин | Что это | Зачем |
|--------|---------|-------|
| **Vivado-проект** (`.xpr`) | Проект: BD, constraints, синтез, place&route | Центральный артефакт аппаратной разработки |
| **Vivado 2016.4 / 2018.3 / 2019.1** | Версии Xilinx IDE | Штатный `top_ctrl` — 2016.4; Elrori — 2018.3; blkf2016 — 2019.1; артефакты между версиями не всегда совместимы |
| **PL-логика / FPGA-код / RTL (Verilog/VHDL)** | Исходники логики в fabric | HDMI, CMOS, кастомные шины; в большинстве репо отсутствует |
| **bitstream** (`.bit`) | Бинарник конфигурации PL | Загружается FSBL/U-Boot; хранится в NAND (`nand-bitstream`); входит в `BOOT.BIN` |
| **`top_ctrl`** | Имя штатного bitstream EBAZ4205 (Vivado 2016.4, ~2 МБ) | Логика управления майнером; исходников в репо нет |
| **`fpga loadb` / `design filename`** | Команда U-Boot и строка в boot log при загрузке bitstream | Подтверждает загрузку PL до ядра Linux |
| **XSA** (раньше HDF) | Экспорт аппаратуры из Vivado для PetaLinux/SDK | Связующее звено HW ↔ софт; в polprog заявлен, но не реализован |
| **ps7_init / `ps7_init_gpl.c`** | Таблицы инициализации DDR, тактов и периферии PS | В FSBL при старте; не карта пинов |
| **xlconcat / xlconstant / xlslice** | IP-блоки Vivado в fabric | blkf2016: обвязка 4-битного PHY к 8-битному GMII (дополнение нулей RX, срез TX) |
| **OOC-синтез** | Out-of-context синтез отдельного IP | Служебный режим Vivado, не привязка платы |
| **Только PS7 без PL-логики** | В fabric нет пользовательского RTL, только оболочка PS7 | KarolNi: bitstream минимальный или отсутствует |
| **`.bin` / `.img`** | Бинарные артефакты (U-Boot, образ карты) | В репозиториях чаще отсутствуют — только исходники для сборки |

## Загрузочная цепочка (boot)

| Термин | Что это | Зачем |
|--------|---------|-------|
| **FSBL** (First Stage Boot Loader) | Первый код после Boot ROM: DDR, опционально bitstream, переход дальше | Обязательный элемент любой Zynq-загрузки |
| **Модифицированный FSBL** (`main.c`, `uboot_loader.c`) | FSBL blkf2016: с SD читает `u-boot.bin` на `0x04000000`, если в `BOOT.BIN` нет приложения | Обход отсутствия U-Boot внутри `BOOT.BIN` |
| **BOOT.BIN** | Образ Xilinx: FSBL [+ bitstream] [+ приложение] | Главный файл для SD/QSPI/NAND |
| **BIF** (`SD_BOOT.bif`) | Текстовый манифест: что положить в `BOOT.BIN` | Рецепт сборки boot-образа |
| **SD-boot** | Загрузка с карты (вместо NAND/flash) | Режим работы; blkf2016 и KarolNi P04 |
| **U-Boot** | Второй загрузчик: FAT, ext4, сеть, меню, передача ядру | Linux-стек; версии 2014.01 (штатный S9), 2019.07-rc4 (blkf2016) |
| **`u-boot.bin`** | Скомпилированный бинарник U-Boot | blkf2016: читается FSBL с FAT-раздела SD |
| **boot.scr** | Скомпилированный скрипт U-Boot (из `.txt`) | Автоматизация загрузки ядра и DTB |
| **uEnv.txt** | Переменные окружения U-Boot (чтение ядра/DTB с SD) | Elrori: сценарий SD-boot |
| **boot log** | Захват UART при включении (`Boot.log`, `bootlog1.log`) | Диагностика штатной и своей загрузки |
| **TFTP** | Загрузка по сети (заявлена в планах polprog) | Альтернатива SD для boot-образов |
| **boot-образы** | Готовые комплекты для загрузки (SD/TFTP) | В polprog заявлены, не реализованы |

## Linux / rootfs

| Термин | Что это | Зачем |
|--------|---------|-------|
| **BSP** (Board Support Package) | Набор под плату: HW-описание + ядро + U-Boot + rootfs | «Проект под железо»; blkf2016 — наиболее полный для EBAZ4205 |
| **Buildroot** (2019.05) | Сборщик минимального Linux (rootfs + toolchain + ядро + U-Boot) | blkf2016: основа SD-Linux |
| **Оверлей Buildroot** | Папка `board/<плата>/` поверх дистрибутива | DTS, конфиги ядра/U-Boot, boot.scr, genimage |
| **linux.config / uboot.config** | Конфигурация ядра и U-Boot под плату | Включение драйверов периферии |
| **Linux 5.1.5 / 3.14 / 4.6** | Версии ядра | 5.1.5 — blkf2016; 3.14/4.6 — штатные Angstrom на S9/EBAZ4205 |
| **zImage** | Сжатое ядро Linux для ARM | Загружается U-Boot с SD |
| **rootfs** | Корневая ФС: `/bin`, `/etc`, библиотеки | Минимальный Linux (OpenSSH, сеть) |
| **rootfs overlay** | Доп. файлы поверх rootfs | Статический IP 192.168.100.1, dnsmasq (blkf2016) |
| **genimage** | Утилита: собрать `sdcard.img` (разделы boot + root) | Готовый образ карты из собранных частей |
| **sdcard.img / SD-образ** | Образ всей SD-карты | Готовый артефакт для записи; в репо обычно не включён |
| **OpenSSH, dnsmasq, статический IP** | Сеть и доступ в rootfs | Конфигурация «голого» Linux вместо майнера |
| **OpenWrt** ([Elrori/openwrt-auto](https://github.com/Elrori/openwrt-auto)) | Альтернативная сборка Linux для EBAZ4205 | Только внешняя ссылка из Elrori |
| **PetaLinux** | Xilinx-сборка Linux из XSA | Заявлен в polprog; в репозиториях почти не реализован |
| **Angstrom** | Дистрибутив Linux на штатных платах Bitmain | Заводская rootfs; bmminer/cgminer |

## Разработка приложений

| Термин | Что это | Зачем |
|--------|---------|-------|
| **bare-metal** | Программа без ОС, напрямую на Cortex-A9 | Альтернатива Linux; KarolNi P01–P04 |
| **Vivado/SDK** | Схема разработки: Vivado (HW) + SDK/Vitis (SW): FSBL + приложение `.elf` | Учебные проекты S9 |
| **Xilinx BSP** (`XGpioPs`, `xilffs`) | Библиотеки доступа к периферии PS | GPIO и FatFs в bare-metal примерах |
| **`.elf`** | Исполняемый файл приложения для ARM | Загружается FSBL или U-Boot |
| **P01_HELLO** | Hello World по UART (`helloworld.c`) | Проверка консоли и BD |
| **P02_GPIO** | Кнопки S1/S2 → LED; опрос `XGpioPs` | Тест MIO GPIO (MIO 47/51/37/38/15) |
| **P03_SD_TEST** | Запись/чтение `test.txt` на SD через FatFs (`sd.c`) | Тест SDIO0 |
| **P04_SD_BOOT** | FSBL → приложение с SD; мигание LED_R/G | Минимальный boot-стек без Linux |
| **FatFs / SD_TEST** | Файловая система FAT на SD в bare-metal | Проверка карты до перехода на Linux |
| **Hello World / UART** | Базовый тест вывода в консоль | Первая проверка живой платы |
| **FSBL + приложение** | Цепочка загрузки без U-Boot/Linux | P04, минимальная прошивка |
| **HDMI soft-decode** | Программный декод HDMI (статьи Elrori) | Вне репозитория — только ссылка |

## Штатная прошивка майнера

| Термин | Что это | Зачем |
|--------|---------|-------|
| **cgminer** (EBAZ4205) / **bmminer** (S9) | ПО управления майнингом на ARM | Штатная логика PS: сеть, мониторинг, обмен с хеш-платами |
| **штатная прошивка / заводская прошивка** | Образ Bitmain/Ebit в NAND | Документируется xjtuecho и polprog; не исходники репозиториев |
| **`nand-bitstream`** | Раздел NAND с bitstream (`top_ctrl`) | PL-логика управления майнером |
| **`/proc` / `proc/cmdline`** | Дампы псевдо-ФС и параметров ядра с работающей ОС | Как штатная система видит NAND, UART, разделы |
| **Инструкции** (сброс пароля, отключение cgminer, сеть, JTAG, питание) | Работа со штатной ОС на NAND | xjtuecho: эксплуатация без новой прошивки |
| **FSBL 2015.4 → U-Boot 2014.01** | Версии загрузчиков штатного S9 (из boot log) | Ориентир при сборке своей цепочки |
